## 🌟 Key Features

- 🎨 **Glassmorphism Aesthetic:** Modern backdrop-filter blur with ambient glowing neon gradient orbs.
- 🔄 **Dual Tab Sliding Navigation:** Seamless animated transition between **Sign In** and **Create Account**.
- 👁️ **Show / Hide Password:** Quick visibility toggle on all password inputs.
- 📊 **Real-Time Password Strength Meter:** Dynamic visual progress meter (Weak, Medium, Strong) as the user types.
- 🔑 **Interactive "Forgot Password" Modal:** Slide-in modal popup to request a password reset link.
- 🌐 **Social Authentication Buttons:** Stylish Google and GitHub glassmorphic OAuth buttons.
- 📱 **100% Fully Responsive:** Pixel-perfect layout tailored for mobile phones, tablets, laptops, and ultra-wide screens.
- ⚡ **Lightweight & Blazing Fast:** Zero bulky framework dependencies, pure HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Priyanshu-kumar-maurya/Login-page.git
cd Login-page
```

### 2. Run locally
Simply open `index.html` in any modern web browser:
```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

## 🛠️ Built With

- **HTML5:** Semantic markup, accessible input labels, and ARIA attributes.
- **CSS3:** Custom Properties (Variables), Flexbox, CSS Grid, Glassmorphism backdrop-filter, Keyframe Animations.
- **Vanilla JavaScript (ES6+):** Tab animations, real-time input verification, password toggling, and interactive toast feedback.
- **Icons:** [BoxIcons](https://boxicons.com/) & [Font Awesome](https://fontawesome.com/)
